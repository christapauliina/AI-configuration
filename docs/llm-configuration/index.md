# AI Configuration

In most use cases, we don't build AI models ourselves. Instead, we take an already published model and configure it to fit our needs. The good news is that there is a wide range of tools for this, from simply writing better instructions to connecting the model to external data or even retraining parts of it. Understanding what these configuration layers are and how they operate is a good starting point for building reliable systems.

This section builds on LLM Foundations. Reading it first is optional, but useful if you want the background on why models respond to these configurations the way they do.

## Goals

This section explores different ways to configure your AI models and agents. Each chapter pairs a short knowledge base with a practical demonstration. To keep the focus on core principles and workflows, the examples are intentionally straightforward. The demonstrations are illustrated with screenshots from the demo applications and the full source code is available on [GitHub](https://github.com/christapauliina/ai-configuration-examples/tree/master). All demos run on the  GPT-5.2 model deployed via Microsoft Foundry.
